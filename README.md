## Generative AI: RAG with LangChain, measured

Learners build a question-answering service over the internal documents of a fictional freight company (Larkspur Freight Ltd), see it fail in named ways, fix each failure, and measure the result. The lab compares three LangChain pipelines: the model alone, naive RAG (fixed-size chunks, vector search, plain prompt), and improved RAG (superseded documents filtered out, heading-aware chunks, hybrid BM25 and vector search with `EnsembleRetriever`, cross-encoder reranking, and a grounded prompt that cites a source per sentence or answers `NOT_FOUND`).

Held-out test, 45 questions, one run after the code was frozen (`results/2026-11-17_rag_eval/summary.json`):

| Qwen2.5-7B-Instruct | Model alone | Naive RAG | Improved RAG |
|---|--:|--:|--:|
| Correct, answerable questions | 1/37 | 29/37 | 35/37 |
| Confident wrong answers, all questions | 34/45 | 7/45 | 1/45 |
| Outdated policy value given | 1/8 | 5/8 | 0/8 |
| Right document cited | 0/37 | 0/37 | 37/37 |

Results for Qwen2.5-1.5B-Instruct (the model used in class on a free Colab GPU), intervals, the paired comparison and the known weak points are in `code/genai/README.md`. All company facts are invented, and the knowledge base is generated by a seeded script.

## Data Science: your first classifier

Beginners build a classifier on 1,599 Portuguese red wines (UCI Machine Learning Repository, Wine Quality, CC BY 4.0) and learn to judge it honestly. The session opens with a poll on whether 87% accuracy is impressive: a model that always answers "not good" scores 86.6% on the test set and finds none of the 43 good wines. Learners then split the data, watch a decision tree overfit, read a confusion matrix, and choose a decision threshold for a business goal. All numbers come from `results/2026-11-17_ds_lesson/numbers.json`, written by `code/ds/01_analysis.py` with a fixed seed (42).

## Run locally

```bash
pip install -r requirements.txt
python code/ds/01_analysis.py                    # rewrites results/2026-11-17_ds_lesson/numbers.json and figures/ds
cd code/genai && python -m pytest -q tests       # 18 tests, no GPU needed
```

The RAG evaluation can be replayed on a CPU from the stored model replies; see `code/genai/README.md`. The evaluation was frozen with file hashes recorded in `results/2026-11-17_rag_eval/freeze.json` before the single test run.
